# TFG
This project carries out a study of Data Quality (DQ) as a combinatorial optimization problem. The object of this study is completeness, one of the metrics through which DQ is measured. This research consists of the implementation of the hybrid metaheuristic CMSA (Construct, Merge, Solve & Adapt) to obtain solutions to the problem of completeness. In order to determine the performance of the metaheuristic, a comparison is made between the performance of this method and others applied to the same problem, a greedy algorithm and an exhaustive method. The conclusions obtained through the analysis of the results of the experimentation show that CMSA is a fairly competitive method in many aspects in the search for a solution to the problem posed in this TFG.
